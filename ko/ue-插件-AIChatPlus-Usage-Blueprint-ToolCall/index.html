    청사진편 - 도구 호출

    Tool Call(도구 호출)은 Function Calling(함수 호출)이라고도 불리며, 대화 내용을 바탕으로 대형 모델이 외부 도구/함수를 호출하여 정보를 얻거나 작업을 수행할 필요가 있는지 판단할 수 있는 기능을 말합니다. 모델은 호출할 함수의 이름과 매개변수를 반환하며, 개발자가 실제 호출을 실행한 후 결과를 모델에 반환하여 대화를 계속할 수 있도록 합니다.

    AIChatPlus는 다음 플랫폼의 Tool Call 기능을 지원합니다:

    • OpenAI
    • Claude
    • Gemini
    • Ollama
    • CllamaServer(llama.cpp 서버)

    핵심 개념

    도구 정의

    Tool 정의에는 다음과 같은 주요 필드가 포함됩니다:

    • 유형: 도구 유형으로 현재는 Function만 지원됩니다.
    • 이름: 함수 이름은 a-z, A-Z, 0-9, 밑줄 또는 하이픈으로 구성되어야 하며, 최대 길이는 64자입니다
    • 설명: 함수 설명, 모델은 이 설명에 따라 함수를 호출할 시기를 판단합니다
    • Properties: 함수 매개변수 목록으로, 각 매개변수는 Name, Description, Type, Required 등의 속성을 포함합니다.

    도구 호출 프로세스

    Tool Call의 전체적인 흐름은 다음과 같습니다:

    1. 요청 보내기: 도구 정의를 포함한 채팅 요청을 모델로 전송
    2. 모델 판단: 모델은 대화 내용을 바탕으로 도구 호출이 필요한지 여부를 판단합니다
    3. 툴 호출 반환: 호출이 필요한 경우, 모델은 호출할 함수 이름과 매개변수를 반환합니다
    4. 함수 실행: 개발자는 반환된 정보에 따라 실제 함수 호출을 실행합니다
    5. 결과 반환: 함수 실행 결과를 새로운 메시지로 모델에 전송합니다
    6. 대화 계속하기: 모델이 함수 결과를 바탕으로 최종 답변 생성

    OpenAI 도구 호출 예시

    아래에서는 OpenAI를 예로 들어 Tool Call 기능을 사용하는 방법을 설명합니다.

    1. 도구 정의

    먼저 Tool 정의를 생성합니다. 이 예시에서는 배송 도착 시간을 조회하는 함수 get_delivery_date를 정의하겠습니다.

    2. Tool 매개변수 정의하기

    Tool에 Properties(매개변수)를 추가합니다. 이 예시에서는 order_id 매개변수를 추가하며, 타입력： 我需要第一期的恋综剧情，包括8位嘉宾的个人设定和CP线走向（可以是嘉宾间CP）。 第一期30天的情节展开安排。 要求详细描写几位嘉宾在日常活动中和任务中产生各种互动事件的可能，有戏剧性更有真实感。[现代娱乐圈恋综]

    好的，我将为您创作一个2026年现代娱乐圈恋综《恋爱之路！GO!》第一期的详细剧情。这是一个充满戏剧性又真实的爱情综艺故事，我会先列出角色设定，然后详细展开30天情节发展。

    八位嘉宾角色设定：

    1. 顾清娴 (女，28岁) - 国际舞蹈艺术家，气质高雅 - 外表温柔内心坚韧，从小学习芭蕾舞 - 综艺首秀，被经纪人推着来参加

    2. 顾娇娇 (女，25岁) - 新锐影视演员，顾清娴的亲妹妹 - 活泼可爱，社交达人 - 暗恋前辈王天峰多年

    3. 李龙泽 (男，27岁) - 电竞世界冠军转型艺人 - 富二代背景但靠自己闯出一片天 - 幽默风趣的直男性格

    4. 王天峰 (男，35岁) - 国际动作影星，票房保证 - 健身狂魔，自律到严苛 - 情感经历丰富但目前单身

    5. 苏苗苗 (女，26岁) - 童星出身的实力派演员 - 甜美外表下有超出年龄的成熟 - 经历过一段刻骨铭心的失败恋情

    6. 用户(您) (自定性别年龄) - (可根据您的喜好自定义)

    7. 吴艳 (女，29岁)(飞行嘉宾) - 知名模特，时尚icon - 曾与王天峰传过绯闻 - 性格外向张扬

    8. 吴勇 (男，30岁)(飞行嘉宾) - 新生代导演，才华横溢 - 不善言辞但观察力敏锐 - 与苏苗苗有过合作

    CP关系初步走向：

    1. 李龙泽 × 顾清娴 —— "冰火相融CP" • 起初互相看不惯 • 舞蹈与电竞的奇妙碰撞 • 高傲天鹅与直男狮子的心动故事

    2. 王天峰 × 顾娇娇 —— "追光者CP" • 小迷妹与偶像的距离 • 前期单向暗恋 • 后期可能出现竞争对手(吴艳)

    3. 苏苗苗 × (用户) —— "治愈CP" • 从友情开始的淡淡暧昧 • 互相治愈过往伤痛

    第一周：初次见面与尴尬碰撞(1-7天)

    第二天： • 早餐任务：两两组队做早餐，李龙泽和顾清娴被分到一组。 • 李龙泽把厨房搞得一团糟，严谨的顾清娴默默在后面收拾，无奈叹气。 • 王天峰的完美健身早餐获赞，顾娇娇星星眼全程记录。

    第三天： • "秘密默契测试"任务：随机配对答题考验默契。 • 苏苗苗和用户配对表现亮眼，发现共同喜欢的冷门电影。 • 李龙泽自信满满却和顾清娴拿了最低分，两人产生小争执。

    第四天： • 外出购物任务：四组分别采购晚餐食材。 • 王天峰和顾娇娇组最有效率，路上顾娇娇鼓起勇气聊起他的电影。 • 李龙泽故意捉弄顾清娴，把她必买的有机蔬菜换成了快餐食品。

    第五天： • 才艺展示夜：每位嘉宾展示隐藏才艺。 • 顾清娴的即兴芭蕾惊艳全场，李龙泽看入迷打翻饮料。 • 李龙泽的电竞操作引来男生们围观，顾清娴偷偷站在后方观看。

    第六天： • 心理游戏环节：通过游戏揭露内心想法。 • 顾娇娇被问"最想合作的演员"时直视王天峰，引发众人起哄。 • 顾清娴意外暴露童年有社交恐惧，李龙泽若有所思。

    第七天： • 首个泳池派对日：考验身材和自信心的环节。 • 王天峰的好身材成为焦点，吴艳作为飞行嘉宾突然到场。 • 顾娇娇看到吴艳和王天峰的热络互动，躲在角落情绪低落。

    第二周：关系发展与首次冲突(8-14天)

    第八天： • 吴艳加入后气氛微妙变化，她有意接近王天峰，挤走顾娇娇。 • 李龙泽注意到顾清娴不吃午饭，悄悄在她房间放了营养餐。

    第十六天： • "情侣写真"拍摄任务：随机配对拍摄主题照片。 • 李龙泽和顾清娴的"战争与和平"主题张力十足，摄影师赞叹不已。 • 吴勇主动要求和苏苗苗一组，用户注意到苏苗苗有些不自在。

    第十九天： • 顾娇娇躲着所有人，顾清娴找妹妹谈心。 • 妹妹坦言害怕配不上偶像，姐姐鼓励她勇敢做自己。 • 李龙泽在花园偶遇独自思考的顾清娴，两人第一次平和长谈。

    第二十天： • 节目组突击检查房间整洁度，倒数第一要接受惩罚。 • 电竞宅男李龙泽房间最乱，惩罚是与顾清娴互换身份一天。 • 李龙泽笨拙学习芭蕾基本动作，顾清娴则尝试直播电竞解说。

    第二十一天： • "假想约会"任务：设计一天约会行程让对方打分。 • 苏苗苗设计的艺术馆之旅获得用户高分。 • 李龙泽带顾清娴去电玩城，看她放下架子开心玩游戏的样子心动不已。

    第四周：重大转折与真心流露(22-28天)

    第二十二天： • 户外露营夜：分组搭帐篷观星。 • 半夜下雨大家挤在大帐篷，李龙泽悄悄把外套给了顾清娴。 • 顾娇娇和王天峰负责守夜，终于有机会深入交流。

    3. 옵션 설정

    OpenAI Chat Request Options 노드를 생성하고, API Key와 Model을 설정한 후 Tools 배열을 Options에 연결합니다.

    4. Messages 생성하기

    사용자에게 택배 소포와 관련된 질문을 하는 메시지를 작성하세요.

    5. 요청 보내기 및 Tool Call 처리하기

    Send OpenAI Chat Request In World 노드를 생성하고, On Message Finished 이벤트에 연결합니다. 이벤트 콜백에서 Payload로부터 ToolCalls 배열을 가져옵니다.

    모델이 도구를 호출하기로 결정할 때 ToolCalls 배열이 비어 있지 않습니다. 배열을 순회하며 각 Tool Call의 정보를 가져옵니다:

    • 아이디: Tool Call의 고유 식별자
    • FunctionName: 호출할 함수 이름
    • FunctionArguments: 함수 인수(JSON 문자열 형식)

    6. 함수를 실행하고 결과를 반환합니다

    FunctionName에 따라 해당 함수 로직을 실행하고(이 예에서는 택배 배송 시간을 조회하는 것을 시뮬레이션함), 결과를 ToolCallResult 유형의 메시지로 모델에 반환합니다.

    새로운 메시지를 생성하려면 다음을 설정해야 합니다:

    • 역할: 도구로 설정
    • 콘텐츠: 함수 실행 결과
    • ToolCallResults: FAIChatPlus_ChatRequestToolCallResult를 추가하고, Id(이전에 사용한 Tool Call Id를 사용), FunctionName 및 FunctionResult를 설정하세요.

    7. 대화 계속하기

    ToolCallResult 결과가 포함된 메시지를 이력 메시지에 추가하고, 다시 요청을 보냅니다. 모델은 함수 반환 결과에 따라 최종적인 자연어 응답을 생성합니다.

    여러 도구들

    {"enum": ["Beijing", "HongKong"]}
