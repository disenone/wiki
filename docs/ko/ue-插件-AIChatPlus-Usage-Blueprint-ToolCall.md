#청사진편 - 도구 호출

Tool Call(도구 호출)은 Function Calling(함수 호출)이라고도 불리며, 대화 내용을 바탕으로 대형 모델이 외부 도구/함수를 호출하여 정보를 얻거나 작업을 수행할 필요가 있는지 판단할 수 있는 기능을 말합니다. 모델은 호출할 함수의 이름과 매개변수를 반환하며, 개발자가 실제 호출을 실행한 후 결과를 모델에 반환하여 대화를 계속할 수 있도록 합니다.

AIChatPlus는 다음 플랫폼의 Tool Call 기능을 지원합니다:

* OpenAI
* Claude
* Gemini
* Ollama
* CllamaServer(llama.cpp 서버)

##핵심 개념

###도구 정의

Tool 정의에는 다음과 같은 주요 필드가 포함됩니다:

* **유형**: 도구 유형으로 현재는 `Function`만 지원됩니다.
* **이름**: 함수 이름은 a-z, A-Z, 0-9, 밑줄 또는 하이픈으로 구성되어야 하며, 최대 길이는 64자입니다
* **설명**: 함수 설명, 모델은 이 설명에 따라 함수를 호출할 시기를 판단합니다
* **Properties**: 함수 매개변수 목록으로, 각 매개변수는 Name, Description, Type, Required 등의 속성을 포함합니다.

###도구 호출 프로세스

Tool Call의 전체적인 흐름은 다음과 같습니다:

1. **요청 보내기**: 도구 정의를 포함한 채팅 요청을 모델로 전송
2. **모델 판단**: 모델은 대화 내용을 바탕으로 도구 호출이 필요한지 여부를 판단합니다
3. **툴 호출 반환**: 호출이 필요한 경우, 모델은 호출할 함수 이름과 매개변수를 반환합니다
4. **함수 실행**: 개발자는 반환된 정보에 따라 실제 함수 호출을 실행합니다
5. **결과 반환**: 함수 실행 결과를 새로운 메시지로 모델에 전송합니다
6. **대화 계속하기**: 모델이 함수 결과를 바탕으로 최종 답변 생성

###5. 요청 보내기 및 Tool Call 처리하기

모델이 도구를 호출하기로 결정할 때 ToolCalls 배열이 비어 있지 않습니다. 배열을 순회하며 각 Tool Call의 정보를 가져옵니다:

* **아이디**: Tool Call의 고유 식별자

###6. 함수를 실행하고 결과를 반환합니다

FunctionName에 따라 해당 함수 로직을 실행하고(이 예에서는 택배 배송 시간을 조회하는 것을 시뮬레이션함), 결과를 ToolCallResult 유형의 메시지로 모델에 반환합니다.

새로운 메시지를 생성하려면 다음을 설정해야 합니다:

* **역할**: `도구`로 설정
* **콘텐츠**: 함수 실행 결과
* **ToolCallResults**: `FAIChatPlus_ChatRequestToolCallResult`를 추가하고, Id(이전에 사용한 Tool Call Id를 사용), FunctionName 및 FunctionResult를 설정하세요.

###복잡한 매개변수 유형

Tool 파라미터는 여러 타입을 지원하며, `ExtraJsonString` 또는 `ExtraJsonObject` 필드를 통해 더 복잡한 파라미터 정의를 추가할 수 있습니다. 예를 들어 열거형(enum) 타입과 같은 경우도 포함됩니다:

```json
{"enum": ["Beijing", "HongKong"]}
```
